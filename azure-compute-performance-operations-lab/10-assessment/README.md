# 10. 평가와 제출

## 목표

워크숍 전후의 운영 판단 역량과 팀 결과물을 측정합니다.

## 이 단계에서 배우는 것

- 지식을 기억하는 것과 운영 문제를 해결하는 것의 차이
- 개인 평가와 팀 산출물을 분리해 측정하는 방법
- Before/After를 숫자와 근거로 설명하는 방법
- 기술 변경을 성능·비용·안정성 관점에서 발표하는 방법

## 최종 발표 질문

1. 가장 중요한 병목은 무엇이었는가?
2. 그 결론을 뒷받침하는 지표는 무엇인가?
3. 적용한 변경은 무엇이며 무엇이 달라졌는가?
4. 아직 남아 있는 위험과 다음 조치는 무엇인가?

## 실행

사전·사후 평가는 [`../ASSESSMENT.md`](../ASSESSMENT.md)의 동일 문항을 사용합니다.

제출물:

```text
artifacts/load-tests/baseline-*.csv
artifacts/load-tests/steady-*.csv
artifacts/analysis.md
artifacts/tuning-decision.md
artifacts/incident-timeline.md
```

## 통과 기준

- 개인 사후 점수 12/20 이상
- 사전 대비 20% 이상 향상
- 팀 산출물 14/20 이상
- Before/After 수치와 최소 2개 근거 지표 존재
