# 10. 평가와 제출

## 목표

워크숍 전후의 운영 판단 역량과 팀 결과물을 측정합니다.

## 실행

사전·사후 평가는 [`../ASSESSMENT.md`](../ASSESSMENT.md)의 동일 문항을 사용합니다.

제출물:

```text
artifacts/load-tests/baseline-*.csv
artifacts/load-tests/steady-*.csv
artifacts/analysis.md
artifacts/tuning-decision.md
artifacts/incident-timeline.md
```

## 통과 기준

- 개인 사후 점수 12/20 이상
- 사전 대비 20% 이상 향상
- 팀 산출물 14/20 이상
- Before/After 수치와 최소 2개 근거 지표 존재
